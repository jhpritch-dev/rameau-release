# RUN IT FROM THE ROOT, AND WITHOUT A PATH ARGUMENT. conftest.py at the repository root is
# what puts harness/router on sys.path, and pytest only loads it when the root is the
# rootdir. `pytest harness/router/tests/some_test.py` makes that directory the rootdir
# instead, the conftest never loads, and every bare import fails with a message that looks
# like missing code rather than a missing path entry.
#
# Verified 2026-11-13 to resolve together with requirements.txt and requirements-opt.txt on
# CPython 3.11 via `pip install --dry-run --ignore-installed`.
