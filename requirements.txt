# RAMEAU router -- runtime dependencies.
#
# PROVENANCE IS MARKED PER LINE, because the alternative -- a pin set with no way for a
# reviewer to tell which pins were measured -- is the thing this repository refuses to do
# elsewhere. Two markers are used:
#
#   [frozen]      the version appears in harness/kb/requirements-frozen-1.18.txt, a pip
#                 freeze taken from a running image on the same python:3.11-slim base.
#                 Measured -- but measured for the KB service, not for the router.
#   [unmeasured]  no version evidence exists in this repository. The pin is the current
#                 release as of 2026-11-13, chosen so that the build is reproducible, and
#                 it is labeled so that nobody mistakes it for a measurement.
#
# THE WHOLE SET RESOLVES TOGETHER. Verified 2026-11-13 with
#   pip install --dry-run --ignore-installed -r requirements.txt
# on CPython 3.11. This is not a lock file. See requirements-dev.txt for the test
# dependencies, requirements-opt.txt for guarded optional features, and
# requirements-mcp.txt for the MCP and decomposer paths -- that last file does NOT
# co-install with this one, and it explains why in its own header.
#
# PYTHON 3.11 IS THE TARGET and it constrains real choices here: numpy 2.5.x requires
# 3.12+, so a visitor on this project's own base image would silently resolve to something
# older if the pin were absent.
